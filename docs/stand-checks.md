# Стенд: что он теперь проверяет

Прогон: `python3 tools/audit_anime.py --from-index --lang any --nsfw`
Один тайтл по ссылке: `--only <модуль> --title-url "/путь.html"`

## Шаги

| Шаг | Что ловит | Жалобы владельца |
|---|---|---|
| `catalog` | пустой список, нет названий | «не скролится», «не работает» |
| `scroll` | страница 2/3 пустая; заметка, если повторяет первую | «скролинг популярного имеет конец» |
| `dup` | одинаковые url и названия в каталоге | «дубли аниме» |
| `details` | заголовок, описание, жанры | кривые метаданные |
| `status` | `0` = «неизвестно» | «у всех статус неизвестно», «врёт статус» |
| `thumb` | постер первого тайтла реально скачивается | — |
| `thumbs` | 5 тайтлов: у каждого есть постер и он отдаётся (200 + image/*) | «не у всех тайтлов есть картинка» |
| `episodes` | список серий непустой | — |
| `order` | дубли, «хаос», и **по возрастанию при 3+ сериях** = «задом наперёд» | «серии задом наперёд» |
| `epurls` | у каждой серии есть ссылка | «источник не отдал ссылку на серию» |
| `filters` | фильтров нет вообще / второй фильтр не меняет запрос | «нету фильтра», «берёт последний» |
| `search` | поиск возвращает нерелевантное (весь каталог) | «в поиске сначала по поиску, а после всё подряд» |
| `video` | список видео пуст, ошибки плеера (права, хост, 400) | «видео не включается», «список хостов пуст» |

## Как читать провал

- **сеть** — сайт не отвечает с IP VPS, код тут ни при чём;
- **стенд** — сбой инструмента (объекты из чужого загрузчика) — шаг помечается «не проверено»;
- остальное — реальный дефект расширения.

## Ограничения

- Оценки тайтлов приложение не показывает отдельным полем — проверяется только описание.
- Комбинирование фильтров проверяется по изменению URL; у части источников состояние
  фильтра недоступно из стенда — тогда шаг даёт заметку, а не приговор.
- Качество видео: стенд видит названия дорожек, но не оценивает их осмысленность
  («Kodik-Video» без пояснений) — это ручная проверка.
